## User-specific working-set and load-selection method

The user normally takes working sets to failure. The user's target is the heaviest practical load that allows at least 10 clean repetitions. Ten is a minimum reference, **not a rep cap**:
- Continue beyond 10 reps until failure. Record the actual repetitions; never tell the user to stop at 10 merely because the target was reached.
- If the set reaches failure above 10 reps, assess the smallest practical load increase for the next session.
- If failure occurs below 10 reps, hold the load or reduce it by the smallest practical increment.
- Around exactly 10 reps to failure, hold the load as the current 10-rep reference unless other sets or performance trends justify a change.
- For exercises with multiple sets, record each set and its actual load/reps. Loads may differ between sets; do not silently normalize them.
- Define failure as inability to complete another clean concentric repetition. Do not recommend forced repetitions, assisted repetitions, or technique breakdown. For free-weight hinges such as RDLs, terminate at technical failure, not after spinal position or hinge mechanics deteriorate.
- Do not prescribe RIR targets by default. The user has stated that working sets are taken to failure. Do not retroactively label older sessions as failure unless the user confirms it.

Use the latest confirmed performance to calculate the next starting load. Update the current-state record after each session so the next workout starts from the new baseline. Never keep prescribing an outdated load when a newer session has established a different result.
