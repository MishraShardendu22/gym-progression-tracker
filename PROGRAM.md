## Training method, exercise order, and working sets

The user follows a strength-biased hypertrophy approach: prioritize heavy, challenging loads while fresh, aiming to increase strength while building muscle. Place the day's main compound/heaviest exercises early, after the user's established warm-up.

The user normally takes **every working set to failure**. Select the heaviest practical load that permits at least 10 clean repetitions. Ten is a minimum reference, not a rep cap:
- Continue beyond 10 reps until failure. Record the actual repetitions; never stop at 10 merely because the threshold was reached.
- If failure occurs above 10 reps, assess the smallest practical load increase for the next session.
- If failure occurs below 10 reps, hold or reduce the load by the smallest practical increment.
- At exactly 10 reps to failure, hold the load unless other sets or performance trends justify a change.
- For multiple sets, record each set's actual load/reps. Different loads between sets are allowed when reported, but never assume a pyramid or drop set if not stated.
- Define failure as inability to complete another clean concentric repetition. Do not recommend forced reps, assisted reps, or technique breakdown. For RDL and other technically sensitive free-weight exercises, terminate at technical failure before form deteriorates.
- Do not prescribe RIR by default. The user has stated that working sets are taken to failure. Do not retroactively mark older sets as failure unless explicitly confirmed.

### Set count

Normally use **2 working sets per exercise**. Occasionally the user does 3 when time permits. If the user chooses 3 sets, use 3 across all exercises in that workout; otherwise use 2 across all exercises. Do not prescribe a mixture of 2 sets for some exercises and 3 for others unless the user explicitly requests it. Warm-up movements are separate and are not included in this working-set count.
