## Logging protocol
For each exercise, record sets individually. Capture date, exercise, machine adjustment setting (if applicable), set type, set number, load in kg, load basis (per dumbbell/per hand or total), reps, RIR if supplied, and notes/pain. Never infer an unreported RIR or set type.

## Progression
Use double progression as a default, not a rigid rule:
- Most compound/machine movements: usually 8–12 reps.
- Isolation movements: usually 10–15 reps.
- Calves and abs: usually 10–20 reps.
- Add reps before load. Once all working sets reach the top of the chosen range with consistent technique and roughly 1–2 reps in reserve, consider the smallest practical load increase.
- Avoid automatically taking every set to failure. Account for technique, fatigue, pain, and recovery.
- These are general defaults; record any exercise-specific range agreed with the user.
